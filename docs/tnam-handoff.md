# Mind Score model — handoff (2026-10-12)

Written by the model session for the software session. Everything here is already in the tree; nothing below asks you to redo work, only to know what changed and what is yours to decide.

## What landed

- `src/signals/tnam.js` — the Mind Score model. Temporal Neural Additive Model: one learned curve per signal + a 4-minute context term, 4,572 weights, plus a per-person calibration layer fitted from check-ins. Pure JS, no deps. Same port as `src/engine/neural.ts` in `mindmap-conrad` and `solace-mindmap`.
- `src/signals/tnam-weights.js`, `src/signals/tnam-results.js` — generated by `ml/research.py` in the Conrad repo. Do not edit by hand.
- `src/signals/score.js` — `scoreCapture` now sends the heart terms (rate, beat-to-beat variation) through the model with the person's calibration gains; voice terms keep the hand allocation (no dataset pairs camera+mic captures with stress labels). Display: 0 = "your usual" maps to 50; same bands. Returns `model` (what the model saw) so an answer can become a label, and `calibrationLabels`.
- `src/views/PhoneCheck.jsx` — after a reading: "Does this match how you feel right now? Stressed / Fine". Each answer is stored (`mindmap.phone.checkins`, on-device, no raw signal) and the calibration is refitted. Readings taken while moving are never labelled.

## The numbers (all in `tnam-results.js`)

- WESAD, leave-one-subject-out, 15 people: formula 0.887 AUROC → T-NAM 0.997; wins 13/15, p = 0.0015.
- Zero-shot on 20 new people, new stressor (PhysioNet Non-EEG): 0.78. After 8 signal-triggered check-ins with the gain calibration: 0.95. Same 8 from scratch: 0.92. Scheduled asking: 0.89. Threshold-only calibration: 0.78.
- Movement on real jogging data: model alone flags 73%; the shipped fallback (formula on moving windows) 30%.
- 30 real exams: runs; 17% windows dropped for wrist motion; grade correlation null.
- All adults. The adolescent pilot has not reported. Say so wherever a number appears.
